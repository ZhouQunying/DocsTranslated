# Docs hubs

## 架构精读

> 跳过不影响阅读翻译正文。

### 文档中心——为什么需要"主地图"？

文档中心（Docs hubs）是平台文档的主地图，提供"链接到每个 OpenClaw 文档的中心"。用户可以"发现每个页面，包括左侧导航中不出现的深度探索和参考文档"。新用户建议从入门指南开始。

这跟网站地图（sitemap）是一个思路——普通导航只显示"主要页面"，网站地图显示"所有页面"（包括隐藏的、深层的）。文档中心让"新用户快速入门"和"老用户深度探索"都成为可能，避免"只看到冰山一角"。

### 主题分类——为什么按领域组织？

结构布局按主题分类资源：

- **初始设置**：入门步骤、系统偏好、基础指南
- **部署**：容器化、Nix 包、版本管理
- **基础架构**：智能体循环、记忆保留、会话管理、网络拓扑
- **消息通道**：流行聊天应用集成、webhook
- **系统管理**：网关操作、系统保护、问题解决
- **工具**：命令行参考、自动化任务、网页导航
- **多媒体输入**：硬件节点、声音、视频捕获
- **操作系统**：移动、桌面、浏览器平台指南
- **高级 macOS**：macOS 伴侣应用深度细节
- **扩展**：插件创建、生命周期钩子、清单文件
- **工作空间**：智能体能力、文档模板、工作空间设置
- **项目管理**：致谢、质量保证协议、发布规则

这跟图书馆的杜威十进制分类法是一个思路——按主题分类（而非按时间或作者），让"找相关资料"变为"在同一区域浏览"。主题分类让"领域专家"快速找到"领域相关文档"，避免"线性搜索"的低效。
