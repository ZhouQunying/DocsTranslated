# Docs directory

## 架构精读

> 跳过不影响阅读翻译正文。

### 文档目录——为什么需要"策划链接"？

文档目录（Docs directory）作为集中导航点，提供"策划的常用 OpenClaw 文档链接"。文件索引按不同类别组织资源。

这跟书签管理器是一个思路——浏览器书签栏只显示"最常用网站"，书签管理器显示"所有收藏"。文档目录让"快速访问常用文档"和"完整浏览所有文档"都成为可能，避免"每次都要搜索"。

### 类别组织——为什么按功能分？

资源按功能分类：

- **初始资源**：基础设置、系统偏好、命令语法、智能体路由、网关管理
- **界面和通道**：消息平台、群组通信、多媒体处理
- **原生设备软件**：跨桌面和移动环境的专用应用目录
- **维护和安全**：自动化调度、外部集成、保护措施、问题解决指南

这跟操作系统的"开始菜单"是一个思路——按功能分类（"办公软件"、"系统工具"、"游戏"），而非按安装时间。功能分类让"我想做 X"变为"在 X 类别下找"，比"在所有文档中搜索"更高效。

Docs directory: centralized navigation point offering "curated links to the most used OpenClaw docs."
