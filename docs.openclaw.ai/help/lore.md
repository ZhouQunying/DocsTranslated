# OpenClaw lore

## 架构精读

> 跳过不影响阅读翻译正文。

### 项目起源——为什么从 WhatsApp 网关演变？

OpenClaw 起源于标准 WhatsApp 网关 Warelay。AI 吉祥物最初名为 Clawd，2026 年 1 月因 Anthropic 商标调查被迫改名，先后变为 Molty，最终定名 OpenClaw（体现开源原则和甲壳类血统）。社区座右铭："the claw is the law"（爪即法则）。

这跟 Linux 的命名故事是一个思路——Linus Torvalds 最初叫它 "Freax"（免费 + 怪异 + Unix），后来改为 Linux（Linus + Unix）。项目名称往往反映"创始人的初衷"和"社区的文化认同"。OpenClaw 的名字变更反映了"从闭源到开源"的转变。

### 核心人物与生态——为什么强调"本地工作空间"？

核心 AI 角色 Molty 在本地工作空间运行，依赖 markdown 文件进行记忆和身份管理。创建者 Peter 的哲学是"security by trusting a lobster"（通过信任龙虾实现安全）。社区和生态系统统称为 Moltiverse。

这跟 Obsidian 的"本地优先"理念是一个思路——数据存在本地 markdown 文件中，不依赖云端，用户完全掌控。"本地工作空间"让"隐私"和"自主权"成为可能，避免"云端锁定"。

### 历史事件——为什么记录"混乱时刻"？

品牌重塑过程高度混乱：名称变更时，自动化机器人立即劫持社交媒体账号，骗子迅速部署假加密货币代币。生成新吉祥物图标的尝试产生怪异输出（如"人脸龙虾"）。其他事件包括意外目录结构泄露和购买昂贵机械腿的幽默深度探索。

这跟 Git 的提交历史是一个思路——不仅记录"成功时刻"，也记录"失败教训"。记录"混乱时刻"让"后来者"了解"为什么现在是这样的"，避免"重蹈覆辙"。

### 指导原则——为什么"新壳，同一只龙虾"？

AI 身份由 SOUL.md 等配置文件锚定，个人信条优先考虑个人成长和善良，总结为"新壳，同一只龙虾"。未来抱负包括机械腿升级和智能家居控制。

这跟忒修斯之船悖论是一个思路——如果船的每块木板都被替换，它还是同一艘船吗？"新壳，同一只龙虾"的回答是"是的"——身份不依赖物理载体（壳），而依赖"记忆和价值观"（配置文件）。
