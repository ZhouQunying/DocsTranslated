# Agents

**总结：** Agent 作用域配置——`agents.*`、`multiAgent.*`、`session.*`、`messages.*`、`talk.*` 下的配置项。channels、tools、gateway 运行时等顶层 key 见 Configuration reference。

> **类比：K8s Deployment template + HPA + 多 Deployment 路由。** Deployment template 定义 pod 基线（image/env/resources），HPA 按规则自动伸缩，多 Deployment 通过 Ingress 路由流量。OpenClaw agents 类似——`agents.defaults` 定义全局基线（workspace/model/skills/heartbeat/compaction/sandbox），`agents.list[]` 数组定义多 agent 实例（覆盖 defaults 任意字段），`multiAgent.routing` 按消息属性（channel/sender/group）路由到不同 agent，session 管理对话生命周期（per-sender/global 作用域、daily/idle 重置、跨 channel identity link）。
>
> **架构要点：** `agents.defaults`：workspace 路径、repo root、skill allowlist（多目录叠加，后加载覆盖同名）、bootstrap 文件行为（`skipBootstrap` 跳过初始上下文）、context 注入模式、truncation 警告、context budget 归属、image 设置、timezone/time format、model 配置（primary/fallbacks/image/video/music/PDF 模型）、runtime policy（CLI backend）、prompt overlay、heartbeat run、compaction 设置、run retry、context pruning、block streaming、typing indicator、sandbox、per-agent 覆盖；`multiAgent.routing`：binding match field（channel/sender/group）、确定性 match 顺序、per-agent access profile（不同 sandbox/tool 限制）；`session`：scope（per-sender/global）、DM 分组策略、identity link（跨 channel 共享 session）、reset policy（daily/idle）、maintenance 控制、thread binding、send policy；`messages`：response prefix（模板变量）、acknowledgment reaction、inbound debounce（批量快速消息）、TTS 配置（provider setup）；`talk`：macOS/iOS/Android 默认值、provider 配置、voice alias、speech locale、silence timeout、realtime 对话设置。
